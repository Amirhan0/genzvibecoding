# gen z vibecoding — лендинг курса

Статический сайт (`index.html`) + одна серверлес-функция (`api/lead.js`), которая складывает заявки с формы прямо в Telegram.

```
index.html      весь сайт: вёрстка, стили, скрипты, мини-игра
logo.svg        знак отдельным файлом (для соцсетей, аватарок, OG-картинки)
api/lead.js     приём заявок и отправка в Telegram
```

## Как подключить заявки в Telegram

Токен бота нигде в коде не лежит — он живёт в переменных окружения Vercel и в браузер не попадает.

**1. Завести бота**

Написать [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя и юзернейм. В ответ придёт токен вида `12345678:AA...`. Это `TELEGRAM_BOT_TOKEN`.

**2. Узнать свой chat_id**

Написать [@userinfobot](https://t.me/userinfobot) — он ответит числом. Это `TELEGRAM_CHAT_ID`.

**3. Нажать Start у своего бота**

Обязательный шаг: пока ты не начал с ботом диалог, Telegram запрещает ему писать тебе первым, и заявки не дойдут.

**4. Задать переменные в Vercel**

Настройки проекта → Environment Variables → добавить обе переменные (`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`) для окружения Production, затем сделать redeploy — переменные подхватываются только при новой сборке.

## Что делать локально

Если открыть `index.html` двойным кликом, адреса `/api/lead` не существует. Форма это переживёт: она покажет текст заявки и кнопку «Скопировать текст» — человек отправит его в чат руками. Так же она себя ведёт, если функция упала или нет сети.

Чтобы проверить форму вместе с функцией, нужен `vercel dev` — он поднимает и статику, и `api/` локально.

## Что менять под себя

Всё в `index.html`:

| Что | Где искать |
|---|---|
| Ник в Telegram | `const TG = 'ameerqan'` в конце файла + ссылки `t.me/ameerqan` |
| Цена | `20 000 ₸` — в хиро, в блоке цены и в липкой кнопке |
| Количество мест, номер потока | блок `.stats` в хиро |
| Акцентный цвет | `--acid` и `--acid-rgb` в `:root` (две строки, меняют весь сайт) |
| Имя автора | блок `#author` — там сейчас заглушка вместо имени и фото |

## Защита формы

- Скрытое поле-ловушка: боты его заполняют, люди не видят. Такие заявки отбрасываются молча.
- Длина каждого поля обрезается на сервере, имя и контакт обязательны.
- Текст экранируется перед отправкой, чтобы имя с угловыми скобками не ломало сообщение.
